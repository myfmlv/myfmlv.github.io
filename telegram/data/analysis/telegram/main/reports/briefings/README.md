# Telegram Briefings

이 폴더에는 텔레그램 뉴스 브리핑 산출물을 누적 저장한다.

## 목적
- 각 브리핑 시점의 핵심 시장 변수 기록
- 당시 전망과 이후 실제 전개 비교
- 반복/중복 뉴스의 누적 패턴 추적
- 텔레그램 의식 흐름 + 객관 지표 + analyst 해석의 결합 아카이브

## 파일 규칙
- 파일명: `YYYY-MM-DD_HHMM_kst.md`
- 예시: `2026-04-03_0800_kst.md`

## 기본 구조
1. 핵심
2. 시장 해석
3. 객관 지표 스냅샷
4. 전망 / 시나리오
5. 다음 브리핑 전 체크포인트
6. 노이즈/중복 제거 메모
